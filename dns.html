The Domain Name System

Simple Version

DNS is the internet's phone book. You type a name (google.com), DNS finds the number (142.250.183.14). Just like your contacts app converts "Rahul" into his phone number.

Full Lookup Chain

1.Browser & OS: Check hosts file and local DNS cache first.
2.Recursive Resolver: ISP's server does the heavy lifting.
3.Root Server: Points to the right TLD server.
4.TLD Server: Points to the authoritative server.
5.Authoritative NS: Returns the final IP + TTL.
6.Caching: Stored at every level for speed.
